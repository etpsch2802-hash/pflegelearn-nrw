2. Erhobene Daten

Die App erhebt folgende Daten:

  • Name: Wird beim Login freiwillig eingegeben und ausschließlich lokal gespeichert
  • Zugangscode: Wird lokal gespeichert bei aktivierter "Angemeldet bleiben" Funktion
  • Lernfortschritt: Quiz-Ergebnisse, Streak, Karteikarten-Fortschritt — ausschließlich lokal im Browser (localStorage)
  • Einstellungen: Theme-Auswahl, Sound-Einstellungen — ausschließlich lokal

Bei bestimmten Funktionen (Registrierung, Feedback, KI-Assistent) werden Daten an externe Dienstleister übertragen. Details siehe Abschnitt 4.

3. Aufbewahrungsdauer

Alle lokal gespeicherten Daten bleiben auf dem Gerät des Nutzers gespeichert bis:

  • Der Nutzer sie manuell löscht
  • Der Browser-Cache geleert wird
  • Die App deinstalliert wird

Es gibt keine serverseitige Speicherung oder Aufbewahrungsfrist da keine Daten an unsere Server übertragen werden.

4. Drittanbieter

Stripe Inc. (Zahlungsabwicklung)
Bei Zahlungen werden Daten an Stripe Inc. übertragen. Es gelten die Datenschutzbestimmungen von Stripe.

Supabase Inc. (Datenbank & Konten)
Konto-, Zugangs- und Abodaten (z. B. E-Mail-Adresse, Freischaltstatus) werden in einer Datenbank bei Supabase gespeichert und verarbeitet. Es gelten die Datenschutzbestimmungen von Supabase.

Vercel Inc. (Hosting)
Die App wird über Vercel gehostet. Vercel kann Server-Logs (IP-Adressen, Zugriffszeiten) speichern. Es gelten die Datenschutzbestimmungen von Vercel.

EmailJS (E-Mail-Versand)
Bei Registrierung und Feedback werden Name und E-Mail-Adresse über EmailJS verarbeitet. Es gelten die Datenschutzbestimmungen von EmailJS.

Groq Inc. (KI-Assistent)
Anfragen an den KI-Assistenten werden an Groq übertragen. Es gelten die Datenschutzbestimmungen von Groq.

5. Datenlöschung und deine Rechte

So löschst du deine Daten:

  • In der App: Hamburger-Menü → Einstellungen → "Alle Daten löschen"
  • Manuell im Browser: Einstellungen → Datenschutz → Website-Daten löschen → pflegelearn-nrw.vercel.app
  • Per E-Mail-Anfrage: kontakt@plan-nrw.de

6. Cookies

Die App verwendet keine Cookies. Lernfortschritte werden ausschließlich über localStorage des Browsers gespeichert.

7. Minderjährige

Die App richtet sich an Personen ab 16 Jahren (Pflegeazubis). Es werden keine Daten von Kindern unter 16 Jahren bewusst erhoben.
